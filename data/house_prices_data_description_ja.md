## SaleType

**売却・契約の種類**

| 値    | 意味                                   |
| ----- | -------------------------------------- |
| WD    | 一般的な保証付き譲渡証書による通常売買 |
| CWD   | 現金による保証付き譲渡証書             |
| VWD   | VAローンによる保証付き譲渡証書         |
| New   | 新築住宅を建築後に売却                 |
| COD   | 裁判所・遺産関連の譲渡                 |
| Con   | 頭金15%・通常条件の契約                |
| ConLw | 低頭金・低金利の契約                   |
| ConLI | 低金利契約                             |
| ConLD | 低頭金契約                             |
| Oth   | その他                                 |

## SaleCondition

**売却時の状況**

| 値      | 意味                                                            |
| ------- | --------------------------------------------------------------- |
| Normal  | 通常売却                                                        |
| Abnorml | 通常ではない売却。交換、差し押さえ、ショートセールなど          |
| AdjLand | 隣接土地の購入                                                  |
| Alloca  | 関連する2物件を別々の権利書で売却。例：コンドミニアム＋ガレージ |
| Family  | 家族間売買                                                      |
| Partial | 最終査定時点で未完成だった住宅。主に新築住宅                    |
